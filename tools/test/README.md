# Ảnh bài làm mẫu để thử máy chấm

`bai-giay-mau-buoi1.jpg`: bài giấy buổi 1 đánh máy giả chữ viết, có sẵn vài câu sai (A.2, A.5, B.2, B.6, C.3, D.3, E.4, G.2) và đoạn viết có lỗi (encourage, am revise). Dùng với hàm `kiemTraChamBai` trong tệp KiemTraKhoa.gs của dự án Apps Script để thử trọn luồng chấm: trắc nghiệm → chép bài viết → xác nhận → bản thường → bản trả phí. Hàm tự xoá dữ liệu thử sau khi chạy.
